Politique de confidentialité — toktool

Dernière mise à jour : 24 juillet 2026

toktool est un outil personnel et open source qui permet à son utilisateur de créer un clip vidéo à partir d'une URL YouTube et de le publier sur son propre compte TikTok, via l'API officielle TikTok.

Données traitées

  • Jetons d'accès TikTok : obtenus lorsque l'utilisateur connecte son propre compte. Ils sont stockés localement sur la machine de l'utilisateur (fichier ~/.toktool/) ou dans les secrets de son dépôt GitHub privé. Ils servent uniquement à publier des vidéos sur le compte de l'utilisateur.
  • Vidéos : téléchargées temporairement, découpées, puis envoyées au compte TikTok de l'utilisateur. Elles ne sont pas conservées au-delà du traitement.

Ce que nous ne faisons pas

  • Aucune donnée n'est collectée, revendue ou partagée avec un tiers.
  • Aucun serveur central : l'outil s'exécute sur la machine ou le compte GitHub de l'utilisateur.
  • La page de connexion ne stocke ni ne transmet aucune information ; le code d'autorisation reste dans le navigateur de l'utilisateur.

Suppression des données

L'utilisateur peut à tout moment révoquer l'accès depuis les réglages de son compte TikTok et supprimer le fichier ~/.toktool/ ou les secrets GitHub correspondants.

Contact

Code source et contact : github.com/BuloJS/toktool.
